# Per-motor parameter registers

Generated by `tools/generate_registers.py`; edit `config_fields.def`.

Byte address = `0x100 + motor * 0x100 + offset`. All words are 32 bits.
Writes are staged until COMMIT is accepted and a control tick occurs.

| Offset | Field | Reset | Units / meaning |
|---|---|---:|---|
| 0x00 | ENABLE | 0 | 0 disabled; 1 speed control |
| 0x04 | TARGET_MRPM | 0 | signed output-shaft milli-RPM |
| 0x08 | ENCODER_PPR | 0 | full pulses per channel per motor revolution |
| 0x0c | GEAR_NUM | 0 | gear reduction numerator |
| 0x10 | GEAR_DEN | 1 | gear reduction denominator |
| 0x14 | WHEEL_RADIUS_UM | 0 | effective wheel radius in micrometres; 0 unknown |
| 0x18 | ENCODER_SCALE_PPM | 1000000 | calibrated counts/revolution multiplier |
| 0x1c | COUNTS_PER_REV_Q16 | 0 | derived x4 output-shaft counts/revolution, Q16.16 |
| 0x20 | ENCODER_SIGN | 1 | +1 or -1; normalize forward motion |
| 0x24 | DRIVE_SIGN | 1 | +1 or -1; normalize bridge wiring |
| 0x28 | MAX_SPEED_MRPM | 0 | maximum output-shaft milli-RPM |
| 0x2c | MAX_ACCEL_MRPM_S | 0 | maximum target acceleration, milli-RPM/second |
| 0x30 | NOMINAL_VOLTAGE_MV | 0 | motor rated millivolts; metadata |
| 0x34 | CURRENT_LIMIT_MA | 0 | requested driver limit; 0 unspecified; requires driver support |
| 0x38 | PWM_HZ | 20000 | requested PWM carrier; platform shell applies |
| 0x3c | SAMPLE_HZ | 1000000 | requested encoder sample rate; platform shell applies |
| 0x40 | FILTER_SAMPLES | 5 | equal input samples required; platform shell applies |
| 0x44 | KP_Q16 | 0 | duty/RPM proportional gain, Q16.16 |
| 0x48 | KI_Q16 | 0 | duty/(RPM second) integral gain, Q16.16 |
| 0x4c | KD_Q16 | 0 | duty second/RPM derivative gain, Q16.16 |

| 0x54 | D_ALPHA_Q16 | 65536 | derivative filter weight, 0..65536 |
| 0x58 | I_LIMIT_Q16 | 65536 | absolute integral limit, normalized duty Q16.16 |
| 0x5c | DUTY_LIMIT_Q16 | 65536 | maximum output duty magnitude, Q16.16 |
| 0x60 | PWM_GAIN_FWD_Q16 | 65536 | positive effort calibration multiplier |
| 0x64 | PWM_GAIN_REV_Q16 | 65536 | negative effort calibration multiplier |
| 0x68 | PWM_OFFSET_FWD_Q16 | 0 | positive effort breakaway offset |
| 0x6c | PWM_OFFSET_REV_Q16 | 0 | negative effort breakaway offset |
| 0x70 | SPEED_ALPHA_Q16 | 8192 | count-window speed estimator filter weight |
| 0x74 | WATCHDOG_US | 100000 | maximum time between host keepalives |
| 0x78 | MAX_DELTA_COUNTS | 4096 | maximum plausible encoder delta per control tick |
